# Candidate Project 1

# Biomedical Problem

This project would allow for improving the efficiency of diagnoses by streamlining how the combination of certain treatments for Wilms' tumour among paediatric patients in different stages.


# Possible RQ
We would like to investigate the efficiency of different treatments (vincristine, dactinomycin, and doxorubicin with or without radiation therapy or observation only) in paediatric patients diagnosed with different stages of Wilms' tumour (Stage I, Stage II, Stage II)

# Dataset
We will be using the AREN0532 dataset from the Cancer Imaging Archive, accessed at this link: https://www.cancerimagingarchive.net/collection/aren0532/


# Biggest Uncertainty 
There is no control group included in this dataset, meaning we would have to retrieve a control group from another dataset for the analysis, which could prove to be challenging when matching for demographic variables such as age, sex, and race.



# Candidate Project 2

# Biomedical Problem
Gliomas are the leading cause of cancer-related death in paediatric patients. Due to how rare this type of cancer is, diagnoses are often delayed, making it essential to predict the development of this type of tumour to ultimately treat this cancer earlier.

# Possible RQ
We would like to investigate how to predict tumour grade in pediatric glioma using multi-sequence MRI. 

# Dataset
We will use the DFCI-BCH-BWH-PEDs-HGG dataset from the Cancer Imaging Archive, accessed at this link: https://www.cancerimagingarchive.net/collection/DFCI-BCH-BWH-PEDs-HGG/

# Biggest Uncertainty 
The biggest uncertainty we will experience is the smaller sample size (n = 61), which would ultimately limit the generalizability of the results obtained. Additonally, the MRI machine used varies between hospitals, which may cause a difference in the image data.
