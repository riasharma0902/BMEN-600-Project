Research Question: Can Radiomic Features Extracted From Multi-Sequence MRI Predict Clinical Outcomes (i.e. Overall Survival) In Pediatric High-Grade Glioma Patients Using The BraTS-PEDs Dataset. 

Dataset Access Instructions: The dataset can be accessed from the TCIA's webpage using this link: https://www.cancerimagingarchive.net/collection/brats-peds/

This dataset is open access and there are no sharing restrictions. 

Map of the Files: From this link, we accessed the Images (Training and Validation) which includes the MR sequences and segmentation masks in the NIfTI file formate. We also used the Imaging Metadata in the TSV format for the completion of the project. 

Steps to Open and Run Progress Check: Download the clinical metadata from TCIA following Section 2.

Open notebooks/preliminary_results.ipynb in Google Colab.

Install any missing packages listed in requirements.txt.

Upload the downloaded metadata to Google Drive and mount Google Drive in Colab, or upload the file directly to the Colab session.

Update the metadata file path in the notebook to match the downloaded file's location.

Run the notebook cells in sequence.
